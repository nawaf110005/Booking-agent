# 03_assets — Visuals

Generated by the project's own renderers (`02_src/scripts/gen_submission_assets.py`),
so they reflect real system output rather than mock-ups.

| File | What it shows |
| --- | --- |
| `seatmap_coldplay_gold.png` | Live seat map for the Coldplay Riyadh **Gold** section — green = available, amber = held, grey = sold. Rendered by `tools/seatmap.py` (Pillow). |
| `seatmap_coldplay_vip.png` | Same renderer for the **VIP** section. |
| `ticket_qr_sample.png` | A QR code encoding an **HMAC-signed** ticket token (booking id + seats + nonce + signature), not a bare booking id — produced by `fulfilment/qr.py`. |

For UI screenshots of the running storefront/chat, record the live app per
`04_presentation/` (the demo video) — these PNGs are the deterministic,
code-generated artifacts.
